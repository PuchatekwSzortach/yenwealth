# yenwealth

yenwealth is a Python library for simulating long-term personal finances in
Japan. It combines income, living costs, investment returns, and account rules
in annual simulations.

Use the guides to understand the model and build a simulation. The generated
API reference documents the Python modules and public classes; open it from the
navigation menu.

## Start here

- [Getting started](getting-started.md) walks through the included examples.
- [Account model](account-model.md) explains the investment accounts and
  deposit and withdrawal priorities.
- [Simulation guides](simulations/index.md) cover deterministic and Monte Carlo
  projections, plus result analysis.

The documentation includes client-side search. Search for an account or class
name such as `NisaAccount` or `MonteCarloSimulator` to find its guide and API
reference.
